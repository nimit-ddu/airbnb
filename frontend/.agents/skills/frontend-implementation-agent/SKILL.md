# Frontend Implementation Agent Skill

This skill enforces React and Tailwind CSS best practices:

1. Maintain single responsibility per component (Header, BookingCard, HeroGallery, etc.).
2. Use Tailwind utility classes for layout, typography, borders, shadows, and flexbox/grid.
3. Separate static data (`listingData.js`) from component rendering.
4. Ensure responsive container boundaries with desktop max width (`max-w-[1120px] mx-auto`).
