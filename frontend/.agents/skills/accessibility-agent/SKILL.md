# Accessibility Agent Skill

This skill ensures frontend accessibility standards:

1. Use semantic HTML tags (`<header>`, `<main>`, `<section>`, `<article>`, `<button>`, `<footer>`).
2. Implement visible focus indicators (`focus-visible:ring-2`).
3. Add proper ARIA labels (`aria-label`, `aria-modal="true"`, `role="dialog"`).
4. Guarantee keyboard focus trap and return focus upon modal close.
