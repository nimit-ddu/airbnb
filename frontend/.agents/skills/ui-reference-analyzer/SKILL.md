# UI Reference Analyzer Skill

This skill provides instructions for analyzing UI reference materials:

1. Extract exact visual elements (Header, Hero Gallery, Specs, Ratings, Booking Widget, Map, Host Card, Footer).
2. Measure approximate desktop layout widths (e.g. 1120px max content container).
3. Document exact color codes (Airbnb Red `#FF385C`, text colors `#222222`, `#717171`, border `#DDDDDD`).
4. Map out interactive states (modals, overlays, dropdowns).
